## `$ ls ~/projects`

<details open>
<summary><strong>MedTrust: Document Fraud Detection Platform</strong> (in progress, team of 3)</summary>
<br/>

A website that detects tampered prescriptions and fraudulent medical reports for pharmacies, hospitals, and insurers. I own the security module: tamper detection, risk scoring, authentication, and Linux deployment.

| | |
|---|---|
| **Stack** | React, FastAPI, PostgreSQL, Tesseract OCR, OpenCV, scikit-learn, Pillow, PyPDF2, pandas, JWT, Docker |
| **My part** | Tamper-detection logic (image forensics and metadata analysis), anomaly scoring, JWT auth and role-based access control, Docker on Linux |
| **Status** | In progress |

</details>

<details open>
<summary><strong>Epidemic Alert Network: Distributed Disease Surveillance System</strong></summary>
<br/>

A multi-node early-warning system modeled on WHO EWARN and CDC BioSense, with 5 simulated clinics reporting to 1 central server over a custom C socket and TCP protocol.

| | |
|---|---|
| **Stack** | C, Python, MySQL, R, Flask, Plotly |
| **Validation** | VMware, VirtualBox, and Cisco Packet Tracer |
| **Outputs** | Real-time dashboard, automated R-generated reports, full system and test documentation |
| **Status** | Core system built; sliding-window surge-detection algorithm in progress |

</details>

<details open>
<summary><strong>DIY Spectrometer v2: Liquid Impurity Analysis</strong></summary>
<br/>

A camera-based spectrometer for analysing impurities such as metals and salts in water and other liquids.

| | |
|---|---|
| **Stack** | Python, OpenCV, NumPy, MongoDB |
| **Features** | Webcam capture, ROI selection, wavelength calibration, peak detection, MongoDB storage, CLI (live, list, plot, compare, export, delete) |
| **Planned** | ML-based impurity classification |

</details>
